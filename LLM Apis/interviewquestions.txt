34. Why can't you directly use response.choices[0].message.content when you receive a streaming response?

37. What is token usage, and how do input tokens and output tokens contribute to total usage?

Token usage means the total number of tokens used in an API request. Input tokens are the tokens we send to the model, such as the user prompt, system message, and conversation history. Output tokens are the tokens generated by the model. So total token usage is input tokens plus output tokens.

38. What is the purpose of response handling in an LLM application?
Response handling means processing the response we receive from the LLM in our application. For example, we can extract the generated text, display it to the user, save it, or use it for another operation.
39. In your code, why did you use AuthenticationError, BadRequestError, and APIError separately?
I used AuthenticationError to handle invalid or unauthorized API keys. I used BadRequestError is used when we send an invalid or incorrectly formatted request to the API. For example, if you send an invalid model name or an unsupported parameter, the API can return a BadRequestError.
I used APIError as a broader exception to catch other API related errors.

40. If your API request fails with a specific error, how would you determine whether the problem is the API key, model name, request parameters, quota, or the API provider itself?


I would first check the exception type, status code, and error message. An AuthenticationError suggests an API key or authorization problem. A BadRequestError can indicate an invalid model or request parameter. A rate limit or quota error indicates a usage or billing limit. For other API errors, I would check the provider’s error details and documentation.

2- what is tokenization and......
- Tokenization is the process of breaking text into smaller units called tokens so the model can process them as numbers. A tokenizer can use words, characters, or subwords. Modern LLMs commonly use subword tokenization, such as BPE, because it can handle common words efficiently while also handling unfamiliar words by breaking them into smaller pieces. The tokenizer converts these tokens into token IDs, which the model then processes. The model uses these tokens to predict the next token.
3- Describe the difference between fine‑tuning an LLM and using prompt engineering to adapt it to a new task.
Fine tuning means training an already trained LLM on task specific data, which updates its model parameters or weights so it becomes better at that specific task. Prompt engineering does not change the model weights. Instead, we design the prompt with clear instructions, context, examples, or constraints to guide the existing model. Prompt engineering is usually cheaper and more flexible, while fine tuning requires task specific data and more computation. For example, I might use prompt engineering to make an LLM summarize customer reviews, but fine tune it if I need consistent behavior for a specific task across many requests.
